# Asset manifest

No image, video, model or audio generation service is used at runtime or was needed to produce assets. Blender is not installed on the build machine; all 3D geometry is generated procedurally in code, deterministically (seeded PRNG), so the world is identical on every visit.

## Audio (`src/audio/AudioEngine.ts`)

All synthesized in the browser with Web Audio: four-voice drone pad (sine + detuned triangle, slow low-pass LFO) re-voiced per chapter; band-passed noise "air"; Karplus–Strong plucked strings tuned to D major pentatonic (one per capability string), cached per pitch; cues for chapter change, approval, success, failure, step tick, forget and focus. Rate-limited (45 ms between plucks, per-cue throttles) and capped at six simultaneous strings.

## Source vs. production

- Source assets: `src/`, `public/`, `index.html`.
- Production output: `dist/` (generated by `npm run build`, not committed).
- Test evidence: `test-artifacts/` (screenshots, performance JSON, e2e log).
