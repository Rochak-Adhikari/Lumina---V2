## 3. Storage Design & Database Path Resolution

### 3.1 Runtime Path Resolution
`lumina/config.py` defines `config.runtime_root`:
```python
@property
def runtime_root(self):
    return Path(self.state_root) if self.state_root is not None else self.root
```
`WaypointStore.for_config(config)` resolves the database path to:
```python
Path(config.runtime_root) / "earth.sqlite3"
```
When `LUMINA_STATE_ROOT` (`config.state_root`) is configured, `earth.sqlite3` resides in that durable state directory; otherwise it resolves under `config.root`. It never relies on `Path.cwd()` at call time and never touches `memory.sqlite3` or Brain Dump tables.

### 3.2 Schema Definition
Initialized idempotently via `CREATE TABLE IF NOT EXISTS`:
```sql
CREATE TABLE IF NOT EXISTS waypoints (
    seq INTEGER PRIMARY KEY AUTOINCREMENT,
    id TEXT NOT NULL UNIQUE CHECK (length(id) = 32),
    name TEXT NOT NULL CHECK (length(trim(name)) BETWEEN 1 AND 120),
    latitude REAL NOT NULL CHECK (latitude BETWEEN -90.0 AND 90.0),
    longitude REAL NOT NULL CHECK (longitude BETWEEN -180.0 AND 180.0),
    description TEXT CHECK (description IS NULL OR length(description) <= 2000),
    category TEXT CHECK (category IS NULL OR length(category) BETWEEN 1 AND 32),
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);
```
- **Ordering key:** `seq INTEGER PRIMARY KEY AUTOINCREMENT` guarantees strictly monotonic, deterministic insertion ordering (`ORDER BY seq ASC`) even when two waypoints share the same millisecond timestamp.
- **Public identifier:** `id` is a server-generated 32-character lowercase hexadecimal UUIDv4 (`uuid.uuid4().hex`), indexed via its `UNIQUE` constraint.
- **No speculative `metadata` column:** Omitted per section 3 guidelines because no current P1.4 requirement justifies arbitrary JSON blobs.

### 3.3 Connection Lifecycle, Transactions, and Journal Mode
- **Short-lived connections with guaranteed closure:** Every store operation opens a connection with `contextlib.closing(sqlite3.connect(self.path, timeout=5.0, isolation_level=None))` and sets `PRAGMA busy_timeout = 5000`. Connections are closed immediately when the operation returns, verified on Windows by unlinking the database file directly after `create()` and `list()`.
- **Journal mode decision (default rollback journal, not WAL):** Because the store uses short-lived per-operation connections and tests/temporary directories frequently create and immediately remove SQLite files on Windows, default rollback journal mode avoids lingering `-wal` / `-shm` sidecar files while providing full ACID serialization with `BEGIN IMMEDIATE`.
- **Explicit atomic transactions:** Multi-statement writes (`create` and `update`) execute inside explicit `BEGIN IMMEDIATE ... COMMIT` blocks with `ROLLBACK` on any `BaseException`.

## 4. REST API Contract

All waypoint endpoints require the local session token header `X-Lumina-Token: <token>` (obtained from `GET /api/config`), matching Lumina's existing boundary and handler conventions.

### 4.1 `GET /api/earth/waypoints`
Lists waypoints in deterministic insertion order (`seq ASC`).
- **Query parameters:** `limit` (optional integer `1..500`, default `100`), `offset` (optional integer `0..999999`, default `0`).
- **Response `200 OK`:**
```json
{
  "ok": true,
  "waypoints": [
    {
      "id": "1d26d32c24744c33b1821f699b3d3e10",
      "name": "Kathmandu",
      "latitude": 27.70169,
      "longitude": 85.3206,
      "description": null,
      "category": "city",
      "created_at": "2026-10-29T12:48:55.102Z",
      "updated_at": "2026-10-29T12:48:55.102Z"
    }
  ],
  "total": 1,
  "limit": 100,
  "offset": 0
}
```

### 4.2 `POST /api/earth/waypoints`
Creates a new waypoint.
- **Request (`Content-Type: application/json`):**
```json
{
  "name": "Kathmandu",
  "latitude": 27.70169,
  "longitude": 85.3206,
  "description": "Capital of Nepal",
  "category": "city"
}
```
- **Response `201 Created`:**
```json
{
  "ok": true,
  "waypoint": {
    "id": "1d26d32c24744c33b1821f699b3d3e10",
    "name": "Kathmandu",
    "latitude": 27.70169,
    "longitude": 85.3206,
    "description": "Capital of Nepal",
    "category": "city",
    "created_at": "2026-10-29T12:48:55.102Z",
    "updated_at": "2026-10-29T12:48:55.102Z"
  }
}
```

### 4.3 `GET /api/earth/waypoints/{id}`
Retrieves a single waypoint by its 32-hex-character ID.
- **Response `200 OK`:** `{"ok": true, "waypoint": { ... }}`
- **Response `404 Not Found`:** `{"ok": false, "status": "not_found", "error": "Waypoint not found."}`

### 4.4 `PATCH /api/earth/waypoints/{id}`
Atomically updates only the supplied allowed fields (`name`, `latitude`, `longitude`, `description`, `category`). `updated_at` advances only if at least one field value actually changed (`changed: true`).
- **Request:** `{"description": "Updated note"}`
- **Response `200 OK`:**
```json
{
  "ok": true,
  "waypoint": { "...": "..." },
  "changed": true
}
```

### 4.5 `DELETE /api/earth/waypoints/{id}`
Deletes an existing waypoint. Deleting a nonexistent ID returns a deterministic `404 Not Found`.
- **Response `200 OK`:** `{"ok": true, "deleted": "1d26d32c24744c33b1821f699b3d3e10"}`
- **Response `404 Not Found`:** `{"ok": false, "status": "not_found", "error": "Waypoint not found."}`

### 4.6 Validation & Error Semantics
- **Coordinates:** Must be JSON numbers (`int` or `float`, explicitly rejecting `bool`, `str`, `list`, `dict`, `null`, `NaN`, `Infinity`, `-Infinity`), finite, with `latitude in [-90, 90]` and `longitude in [-180, 180]`.
- **Strings:** `name` is trimmed and must be `1..120` chars; `description` is optional (`null` or trimmed string up to `2000` chars; empty whitespace normalizes to `null`); `category` is optional (`null` or `^[a-z0-9][a-z0-9_-]{0,31}$`).
- **Unknown fields:** Rejected with `400 Bad Request` (`status: "invalid_argument"`).
- **Status codes:**
  - `400 Bad Request` (`invalid_argument`) — malformed JSON, non-standard JSON constants (`NaN`/`Infinity`), invalid ID format, missing/invalid fields, invalid paging parameters.
  - `403 Forbidden` (`forbidden`) — missing or invalid `X-Lumina-Token` or unrecognized `Host`/`Origin`.
  - `404 Not Found` (`not_found`) — unknown waypoint ID on `GET`, `PATCH`, or `DELETE`.
  - `405 Method Not Allowed` — unsupported HTTP method (e.g., `PUT` on item, `DELETE` on collection).
  - `409 Conflict` (`limit_exceeded`) — waypoint store capacity (`MAX_WAYPOINTS = 10000`) reached.
  - `413 Payload Too Large` (`payload_too_large`) — body exceeds 16 KB.
  - `415 Unsupported Media Type` (`unsupported_media_type`) — `Content-Type` is not `application/json`.
  - `500 Internal Server Error` (`internal_error`) — generic message `"Waypoint storage is unavailable."` with zero SQL, filesystem path, or traceback leakage.
  - `503 Service Unavailable` (`busy`) — SQLite lock timeout.
