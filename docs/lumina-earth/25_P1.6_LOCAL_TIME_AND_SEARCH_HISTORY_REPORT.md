## 3. Key Architecture & Design Decisions

### 3.1 Local Time Intelligence Architecture
- **Zero External API Cost:** Both Open-Meteo geocoding search and weather endpoints already supply authoritative IANA timezone strings (`Asia/Kathmandu`, `Asia/Tokyo`, `America/New_York`, etc.). This completely eliminates any need for external paid timezone lookups or third-party web services.
- **Native ECMAScript Standard (`Intl.DateTimeFormat`):** Native `Intl.DateTimeFormat('en-US', { timeZone, ... })` automatically accounts for:
  - Fractional-hour offsets (Kathmandu `UTC+05:45`, Kolkata `UTC+05:30`, Chatham Islands `UTC+12:45`).
  - Daylight Saving Time (DST) switches (e.g. London GMT vs BST, New York EST vs EDT).
  - Midnight date rollovers across international borders.
- **Single Managed Timer & Pause-on-Hide:** `createLocalTimeController` manages a single `setInterval` timer ticking once per second. Crucially, when Earth is hidden or modal dialogs open, `view.pause()` cascades to `localTimeCtrl.pause()`, halting interval ticks. When returning to Earth, `view.resume()` resumes ticking seamlessly.

### 3.2 Persistent Search History Architecture
- **Shared SQLite Database:** Stored in `<runtime_root>/earth.sqlite3` alongside P1.4 waypoints, maintaining clean schema isolation in the `search_history` table.
- **120-Second Deduplication Window:** If the user searches for or revisits the same place within 120 seconds, the store updates `searched_at = utc_now()` and moves the existing entry to the top rather than accumulating redundant duplicate entries. Distinct geographic locations with identical names (e.g. London UK vs London Ontario) are disambiguated by coordinate proximity check (`|lat - c.lat| < 0.001` and `|lon - c.lon| < 0.001`).
- **Bounded Storage (100 Entries):** An automatic eviction query keeps only the 100 most recent searches (`seq IN (SELECT seq FROM search_history ORDER BY searched_at DESC LIMIT 100)`), keeping database size tiny and operations sub-millisecond.

### 3.3 Atlas Dual-Tab Experience
- Slide-out `#earth-atlas-panel` now hosts two tabs:
  1. **Saved Places:** Permanent waypoints created and edited by the user.
  2. **Recent Searches:** Automatic exploration history sorted newest-first.
- Each history card displays:
  - Location title with relative timestamp (`formatRelativeTime`, e.g. "Just now", "5m ago").
  - Country and administrative region subtitle.
  - Geographic coordinates and IANA timezone badge.
  - **Revisit Action:** 1-click camera fly-to, marker placement, weather forecast refresh, and local time clock synchronization.
  - **Delete Action:** Instantly deletes single entry from database and DOM.
- **Confirmed Clear Flow:** Clicking "Clear All" displays an inline warning banner asking "Clear all search history?" with "Clear All" and "Cancel" buttons, avoiding accidental wipes.
