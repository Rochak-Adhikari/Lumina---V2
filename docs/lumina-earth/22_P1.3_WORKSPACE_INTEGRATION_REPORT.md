## 2. Integration Architecture: Blueprint Option A Rationale

During preflight inspection, both architectural options from `docs/lumina-earth/20_P1.1_INTEGRATION_AUDIT_AND_BLUEPRINT.md` were evaluated:

1. **Option B (Iframe Embedding):** Rejected.
   - Inspection of `lumina/server.py` confirmed that Lumina’s security middleware strictly enforces:
     ```http
     Content-Security-Policy: ... frame-ancestors 'none'
     ```
   - Relaxing this security header would degrade Lumina's production security posture against clickjacking and frame hijacking.
   - An iframe would also fragment WebSocket state and audio capture contexts.

2. **Option A (In-Place DOM Integration):** Adopted.
   - Direct integration inside Lumina’s `<main class="workspace">` container alongside existing `.presence` and `.environment` sections.
   - Fully compliant with the production CSP policy without server or header modifications.
   - Shared single WebSocket connection (`/ws`) preserving conversation and voice turns across view switches.

### 3.3 Workspace Controller (`web/earth-workspace.js`)
Created a dedicated workspace controller that manages:
1. **Lazy Initialization:** The Three.js WebGL scene is initialized only upon first activation of `#earth-open`, preventing unnecessary GPU allocation on initial application boot.
2. **View Switching:** Clicking `#earth-open` hides the chat presence and environment views, displays `#earth-workspace`, sets `aria-current="page"`, and resumes rendering. Clicking `[data-focus]` navigation buttons (Dashboard, Chat, Knowledge) hides Earth and restores the previous view.
3. **Modal Dialog Interleaving:** Opening modal dialogs (`Command Deck`, `Brain Dump`, `Settings`, `Memory`) pauses Earth's rendering loop to ensure 0% GPU utilization while the modal overlay is active, and resumes rendering immediately when the dialog closes.
4. **Visibility & Unload Handling:** Pauses rendering when the browser tab is minimized or hidden (`document.hidden`), and cleanly disposes WebGL textures and event listeners on `pagehide`.

### 3.4 Rendering Lifecycle & Zero-Cost Frame Stoppage (`web/earth/earth-prototype.js`)
- Extended `createEarth` with explicit `pause()`, `resume()`, and `isPaused()` methods.
- **Pause mechanism:** Cancels the active `requestAnimationFrame`, halts the render loop, and marks `container.dataset.rendering = "paused"`.
- **Resume mechanism:** Restarts `requestAnimationFrame`, triggers camera/viewport `resize()`, and marks `container.dataset.rendering = "active"`.
- **Idempotency & Resource Safety:** Guarded `initEarth` to return the existing instance if already initialized, preventing duplicate canvases, duplicate WebGL contexts, or multiple render loops.
