Official sources (recheck before implementation; source text is external evidence, not execution permission):
- [Google pricing](https://ai.google.dev/gemini-api/docs/pricing): free-tier model entries, data-use column, tools pricing; dedicated Computer use is not free-tier eligible in the retrieved table.
- [Google rate limits](https://ai.google.dev/gemini-api/docs/rate-limits): project-specific limits and non-guaranteed capacity.
- [Google Computer Use](https://ai.google.dev/gemini-api/docs/computer-use): model-generated action mechanism; implement local executor. Learn its schema conceptually; do not import sample agent as Lumina's engine.
- [Qwen official model card](https://huggingface.co/Qwen/Qwen3-VL-2B-Instruct): Apache-2.0, image/agent model and runtime examples. Reuse weights only after license/runtime approval; no model download in this task.
- [Microsoft SendInput](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput): accepted event count, UIPI and existing key-state limitations. Use documented API behind typed executor; no extra automation dependency required.
- [Microsoft foreground](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setforegroundwindow): activation can be refused; request then verify.
- [Microsoft bounds](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getwindowrect): DPI virtualization/invisible borders; don't equate raw rectangle with visible capture bounds.
- [Microsoft UIA events](https://learn.microsoft.com/en-us/windows/win32/winauto/uiauto-eventsforclients): scoped events and late callback/lifetime limits; optional optimization, polling verification still required.
- [Microsoft capture](https://learn.microsoft.com/en-us/windows/uwp/audio-video-camera/screen-capture): potential future backend mechanism. Current Lumina uses MSS/Win32; don't replace it absent measured need.
